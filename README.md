### 👀 About Me

I'm a Data Engineer based in Bengaluru, focused on building **end-to-end ETL/ELT pipelines** and **Medallion (Bronze → Silver → Gold) architectures** that turn messy, real-world data into reliable reporting layers. I've processed 5M+ financial transactions for fraud detection, built incremental Databricks pipelines with automated monthly recalculations, and used LLMs to automate sentiment analysis on 8,400+ support tickets.

- 🔭 **Currently building:** incremental Databricks pipelines using PySpark, Delta Lake & Medallion architecture
- 🌱 **Currently deepening:** AWS and Databricks Workflows / orchestration
- 👯 **Looking to collaborate on:** data engineering & analytics projects — ETL pipelines, data warehousing, BI
- 🤔 **Looking for:** Data Engineer opportunities
- 💬 **Ask me about:** Python, SQL, ETL/ELT design, Medallion architecture, Power BI
- ⚡ **Fun fact:** one of my pipelines replaced manual tagging on 8,400+ support tickets using Llama 3.1
